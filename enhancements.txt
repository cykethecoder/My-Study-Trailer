StudyTrailer – Enhancement Features

1. Extra Features Implemented


• Dashboard homepage with personalised welcome message
• “Get To Know You” modal for first-time user setup
• User profile personalisation (name, diploma, semester display)
• Edit Profile / My Profile feature
• Automatic semester prediction and semester progression helper
• Search and filtering for Study Sessions
• Search and filtering for Modules
• Search and filtering for Study Goals
• Goal progress tracking using status (Not Started, In Progress, Completed)
• Dynamic dashboard statistics and counters
• Upcoming exam countdown timer on dashboard
• Grouping records by Year & Semester
• Dynamic module dropdown linking across forms
• Study session image support using image URLs (saved under imgs folder, in resources)
• Bootstrap responsive UI design
• Delete confirmation popups
• Dynamic EJS rendering using loops and conditions
• Automatic form pre-filling using saved profile data
